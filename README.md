# Alexa - Modern Portfolio Website

A clean, modern portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive design (mobile-first)
- Smooth scroll animations
- Animated skill bars
- Portfolio filter with categories
- Contact form with validation
- Particle background effect
- Mobile hamburger navigation
- Scroll-based navbar effects

## Getting Started

Simply open `index.html` in your browser, or serve the project with any static file server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```
